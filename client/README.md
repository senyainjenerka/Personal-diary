# Личный дневник — клиент

Автономное React-приложение на Vite. Серверные запросы не выполняются.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`.

## Структура

- `src/components/` — форма, фильтры, статистика, карточка записи и менеджер списка.
- `src/data/initialEntries.js` — четыре демонстрационные записи.
- `src/hooks/` — хуки localStorage и debounce.
- `src/utils/storage.js` — безопасное чтение, сохранение и удаление данных.
- `src/App.css` — стили приложения.

Записи хранятся в localStorage под ключом `diary:entries`, а незавершённый черновик — под ключом `diary:draft`. Чтобы вернуться к демонстрационному списку, используйте кнопку сброса на странице.
